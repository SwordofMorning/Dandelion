You must strictly follow this Markdown style when generating documents or writing to .md files.

## 1. General Rules
- **NO EMOJIS**: Do not use any emojis (like 🔧, 📅, 📊, 😊, etc.) anywhere in the document.
- **Tone**: Maintain a strictly professional, technical, and academic tone.
- **Language**: Use Chinese for content, but standard mathematical or technical terms can remain in English.

## 2. Heading Structure
Use standard ATX headings (`#`). The heading hierarchy must strictly follow Chinese numeric outlines:

```md
# Document Title

<!-- [toc] If a table of contents is required -->

## 一、First-Level Heading

### 1.1 Second-Level Heading

#### 1.1.1 Third-Level Heading

##### Fourth-Level Heading
